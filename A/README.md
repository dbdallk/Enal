# A — English alphabet vocabulary

This directory is reserved for the letter **A**.

Required dataset:
- A9_1.json through A9_9.json
- exactly 900 unique English entries per file
- 8,100 unique entries total
- JSON object format: `{"english": "Persian"}`
- no duplicate English keys across files
- no fabricated English words
- Persian values must be actual translations, not transliterations

The repository currently does not contain a bilingual English→Persian dictionary, so the
dataset generator intentionally refuses to fabricate missing translations.
